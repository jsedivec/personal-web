# Jiří Šedivec — Personal Website

Osobní prezentační web pro Jiřího Šedivce — učitele pohybu v Plzni a tvůrce webů.

## O projektu

Česká jednostránková prezentace s anchor navigací:
- **O mně** — kdo jsem a moje cesta k pohybu
- **Pohyb** — skupinové lekce, individuály a odkazy na rezervace
- **Weby** — portfolio webových projektů
- **Kontakt** — e-mail, telefon, Instagram a kontaktní formulář

## Tech stack

- [Next.js 16](https://nextjs.org/) — App Router + TypeScript
- [Tailwind CSS](https://tailwindcss.com/) — styling
- Vercel-ready deployment

## Lokální vývoj

```bash
# Instalace závislostí
npm install

# Spuštění dev serveru
npm run dev

# Build pro produkci
npm run build

# Spuštění produkčního buildu
npm start
```

Dev server poběží na [http://localhost:3000](http://localhost:3000).
